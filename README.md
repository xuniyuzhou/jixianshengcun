# 生存保号套餐（survival-budget-meal）

一个面向 AI Agent 的 **极端省钱营养餐 / 生存保号套餐** 技能（Skill）。

当你身处低谷（失业、负债、手头只剩很少钱），需要知道"怎么用最低成本吃饭、守住身体底线"时，本技能提供 **5 套梯度省钱吃饭方案**（单餐约 0.2–2.5 元），包含食材、成本、做法、营养构成与适用人群，并强制输出健康底线提醒与求助渠道。

## 核心原理

人体本质上是一台生化机器，只认四类基础物质：

1. **葡萄糖（碳水）** → 提供动力
2. **氨基酸（蛋白质）** → 修复组织、合成酶
3. **必需脂肪酸（油脂）** → 维持细胞膜
4. **微量元素/维生素** → 催化代谢反应

省钱的关键：用食品工业基础原料（大豆分离蛋白、燕麦原粉、速冻蔬菜、散装杂粮等），绕开包装、品牌、广告与营销溢价。

## 使用方式

将本目录作为 Skill 安装到 AI Agent 的技能库（如 `workspace/.user_skills/`），用户提到以下场景即自动触发：

- 兜里只剩 X 元怎么撑一个月 / 还有没有更便宜的吃法
- 失业、负债、低谷期、走投无路时怎么吃饭
- 省钱吃饭方案、两毛钱一餐、生存保号、营养兜底

## 健康底线（硬性要求）

- 1–2 档为极端应急方案，只能短期过渡，不可长期作为主食。
- 维生素/矿物质片按说明书剂量服用，不超量、不叠加，不能替代正常饮食。
- **禁止建议食用任何非人类食品**（如动物饲料）。
- 兜里极度紧张时，优先提示低保、社区/街道临时救助、公益免费餐等求助渠道。
- 不美化贫穷，方案目的是守住健康底线，不是长期生活方式。

## 数据口径

- 主要素材：抖音「小明科普日记」《你敢信一顿最低仅两毛钱，5套硬核营养食谱，低谷期守住身体底线》（2026-10）。
- 价格与营养数据均为视频口径参考值，未经独立验证，使用时应按"参考值"表述。
